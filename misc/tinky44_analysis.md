# tinky44 作品群 分析ドキュメント

このドキュメントは、tall_life_simulator の作者・tinky44 氏の小説群（全76作品）を分析した結果をまとめたものです。
ゲームの世界観設計・イベント設計・ステージ設計の参考資料として活用します。

出典：https://gredtinky.cloudfree.jp/

---

## 作品の全体傾向

### コアテーマ

> **「普通の世界に存在する、規格外に大きな女の子」との、じっくりとした日常的関係性の体験**

純粋な巨大化フェチではなく、**「リアルな生活スケールの中で、サイズ差を五感で感じる体験」** が核心。
そのためシミュレーターという形式が最も適していた。

---

## カテゴリ別分析

### カテゴリ1：「高身長 × 日常」系（コア・最多）

**代表作：**
転校生 / 長身少女の一日 / 長身姉妹 / お隣の日花里さん / コンプレックスは治らない / 大きな私のありふれた日常 …

**特徴：**
- 身長が高いことで生まれる**日常の摩擦**を丁寧に描く
- ドア・電車・椅子など**生活空間との対比描写**が多い
- 語り手は**普通身長の男性**で「見上げる視点」が基本構造
- 巨身少女は**コンプレックスを抱えつつ受容していく**成長物語

**ゲームへの示唆：**
- 家ステージの各オブジェクトとの「干渉イベント」の重要性
- ドア・天井・シャワーなどで「サイズ差を体感させる」演出

---

### カテゴリ2：「成長・巨大化プロセス」系

**代表作：**
子どもの成長期 / 大きくなったら / SS:ぐんぐんぐん / 超高身長症 / 300cmの世界 / 遺伝子とドーピング / 朝起きたら …

**特徴：**
- **成長するプロセス自体**への強い関心
- 「測定」「数値」「記録」への執着（cm単位で成長変化を追う）
- 医学・科学的な架空設定（「超高身長症」など）で**リアリティを担保**
- スケールがエスカレートする傾向（160cm → 200cm → 300cm → 500cm）

**ゲームへの示唆：**
- **身長数値の可視化・測定イベント** がシミュレーターの中核
- 成長の「驚き」「ショック」「受容」という感情曲線を大切にする

---

### カテゴリ3：「スケール格差」強調系

**代表作：**
小さいお兄さんと大きな少女 / 小さい勇者と大きな村娘 / 大きな私と小さな博士 / 母と娘の親子逆転 / マトリョーシカ / 比べ合い …

**特徴：**
- **「小さい男性 × 大きな女性」** という対比への強い嗜好
- 相対的なサイズ差をファンタジー・現実・家族など様々な設定で試している
- 「母と娘の親子逆転」のような**ヒエラルキー逆転** 要素も含む

**ゲームへの示唆：**
- プレイヤー（視点）とキャラクターの**身長差の相対表示**が重要
- 成長によってヒエラルキーが変化するイベント演出

---

### カテゴリ4：「ファンタジー・SF」系

**代表作：**
高身長女子が転生して勇者パーティーがチートになる話 / 不思議なペンダント / 最終兵器巨大少女 / 屋敷の巨人 / 怪獣の恋 …

**特徴：**
- 現実的な高身長だけでなく、**ファンタジー的巨大化**も対象
- ただし純粋な「ジャイアントフェチ」よりは**社会との関係性**を重視
- ジャンルミックスを楽しむ姿勢

---

### カテゴリ5：「社会・職業・インフラ」系

**代表作：**
インタビュー / 適材適所 / 250cm大物風俗嬢 / 巨大化風俗嬢 / ある電車の一車両で / 外は貴く内は暖かく …

**特徴：**
- 高身長女性が**社会でどう機能するか**への興味
- 電車・社会インフラとの接触描写への執着
- 身体的特異性と経済活動・人間関係の交差

**ゲームへの示唆：**
- ステージ拡張（電車・学校・屋外）の優先度が高い根拠
- 「社会に馴染めるか」というシステムへの親和性

---

### カテゴリ6：「キャラクター長期追跡」シリーズ系

**代表作：**
宮本淳の話 / 宮本春香の話 / 宮本紗也の話 / 高野優希の話 / 高野智子の話 / 沙織ちゃん / 梨緒さん …

**特徴：**
- 繰り返し同じキャラクターを追う**シリーズ形式**への愛着
- **一人のキャラクターの長期的な成長・変化**を追いたい欲求
- ← **tall_life_simulator（シミュレーター形式）に直結する動機**

## 家ステージ設計メモ

`specs/game_story_spec.md` に記載された家ステージの主要オブジェクト。
tinky44 作品での「日常の摩擦」描写と対応させて設計する。

| オブジェクト | 作品内での描写傾向                                    | ゲームでの役割（案）                       |
| ------------ | ----------------------------------------------------- | ------------------------------------------ |
| **ドア**     | 頭がつかえる / かがんで通る / ドア枠に手がとどく      | 身長閾値でアニメーション変化・通過イベント |
| **シャワー** | シャワーヘッドに頭が当たる / 腰より低いヘッドの不便さ | 入浴イベント・身長測定イベントとの連携     |
| **キッチン** | カウンターが膝あたりの高さになる / 作業台への干渉     | 料理イベント・高さ差の可視化               |

## まとめ

tinky44氏の作品群から、tall_life_simulator が目指すべき体験の核心が明確になる：

1. **数値の変化を丁寧に見せる**（cm単位・測定シーン）
2. **日常オブジェクトとの相互作用**（ドア・シャワー・キッチンなど身近なもの）
3. **「見上げる側」の主観的体験**（プレイヤー視点）
4. **長期的な関係性の変化**（シミュレーター時間軸）

これらが揃うことで、作者が小説で表現してきた「体験」がゲームとして再現される。
