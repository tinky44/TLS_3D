# ブレスト：シミュレーター × ゲーム性の両立

> spec.local.md の過去議論 + 現在の実装を踏まえた整理。2026-03-12

---

## 現在の実装でもうあるもの（強み）

- バレー部ストーリー（分岐・選択肢・フラグ管理）
- NPC反応変化（家族・はるか・先生）
- 身長測定イベント・保健室
- かがむアニメーション（スカート物理含む）
- 学校・家などのステージ
- 入学式モノローグ・夏休み急成長

→ **土台は十分ある。「ゲーム性」を後付けで薄く足すのではなく、既存要素を束ねるループとパラメータを定義することが鍵。**

---

## A. コアゲームループの明確化

### 現状の問題
「歩いて探索 → テキストを読む」の繰り返しで、「今日何をするか」の判断がない。

### 案：1日を選択で進める

```
朝 → 「今日どこへ行くか」選択
  └→ 学校 / 繁華街 / 家 / 公園
夕方 → イベント発生 or 比較体験
夜 → パラメータ変動の確認
翌日へ
```

**ポイント：選択の結果に違いがある** ことで「判断」になる

### 案：週・月・学期の時間粒度

- 1操作 = 1週間進む（テンポよく）
- 学期の節目でイベント強制発生
- 夏休みは「特別フェーズ」（過ごし方の選択が数値に影響）

---

## B. パラメータ設計（判断に意味を持たせる）

### 目立ち度 × ストレス のトレードオフ（過去議論より）

| エリア | 目立ち度 | ストレス | 比較オブジェクト |
|---|---|---|---|
| 家・地元 | 上がりにくい | 低い | 鴨居・シャワー・キッチン |
| 学校 | 中程度 | 中程度 | 机・黒板・体育館 |
| 繁華街 | ガンガン上がる | 高い | 自動改札・エレベーター・電車 |
| 公園・吹き抜け | 上がらない | 下がる（回復） | ブランコ・ベンチ・フェンス |

### 疲労システム（かがむことのコスト化）

- 身長が高くなるほど、家の中を歩くだけで疲労が溜まる
- 疲労が高い → イベント選択肢が減る
- 天井の高い場所（公園・体育館）へ行くと回復
- →「どこへ行くか」に物理的な動機が生まれる

### 内面パラメータ（既存の self_confidence / self_complex を使う）

- 目立ち度が高い + 内面が強い → 「有名ルート」
- 引きこもり傾向 + 内面が弱い → 「不登校ルート」
- どちらでもない → 「普通の生活ルート」

## C. 発見・探索要素（Y軸レイヤー）

### 身長閾値でアクセス可能なものが変わる

| 身長帯 | 新たに見えるもの・できること |
|---|---|
| ～160cm | 普通の視界 |
| 170～190cm | タンスの上・棚の天板が見える |
| 200～220cm | 鴨居の上のほこり、換気扇の上 |
| 230cm以上 | 天井近く・高い棚の奥（隠し要素？） |

**初めてアクセスできたとき** の専用テキストが快感になる

### 「初回体験コレクション」

- 初めて頭がドアに当たった日
- 初めて制服のボタンが外れた日
- 初めて電車でつり革に手が届かなかった日（逆方向）
- ゲーム内でこれを「アルバム」として保存 → エンディングで振り返る素材になる

## D. リプレイ性（成長タイプのバリエーション）

過去議論の「成長タイプアンロック」をゲームサイクルに組み込む案：

| タイプ | 特徴 | 面白さ |
|---|---|---|
| ノーマル型 | 標準的な成長曲線 | バランスよく全要素を体験 |
| 晩成・爆発型 | 高校から急激に伸びる | 「普通だった」から「急変」するカタルシス |
| 超早熟型 | 開始時から180cm超 | 小学校の机・ランドセルとのアンバランスを堪能 |
| 限界突破型 | 常に高速で伸びる | 世界が急速に「小さく」なる圧倒感 |

1周目クリアで晩成型がアンロック → 2周目クリアで早熟型… という段階解放

## E. エンディング設計

### 「リザルト発表」型エンディング（過去議論より）

- 成長グラフ（いつ何cmだったか）
- 初回体験コレクションの表示
- 最終身長での「最後の比較スチル」（校門をくぐるシーン等）

### フレーバー分岐（行動パターンで決まる）

- スポーツ系オブジェクトをよく調べた → アスリートルート後日談
- 繁華街で目立ち度を稼いだ → 有名人ルート
- 家・地元だけで過ごした → ひっそり成長ルート
- 不登校フラグ → 別の道ルート

## F. 新しいアイデア（まだ出ていないもの）

### 特注グッズシステム
- 身長が一定を超えると「普通の服・靴が買えなくなる」
- 特注品を作るにはお金（時間リソース）が必要
- → 軽いリソース管理要素

### 記念写真システム
- 主要イベント時に「記念写真」が自動で保存される
- 写真の中でNPCとの身長差が視覚的に記録される
- エンディングのアルバムに使われる

### 相対身長メーター（UIアイデア）
- 画面端に「隣にいるNPCとの身長差」をリアルタイム表示
- 常に自分のデカさを相対的に意識できる

### 「適応チャレンジ」ミニゲーム的要素
- 自動改札のタイミング通過（体が引っかかるギリギリ感）
- 電車のドアが閉まる前に体を押し込む
- → 忙しすぎない程度に。あくまでフレーバー

### SNS・メディア演出
- 目立ち度が高くなると「ネットで話題に」「テレビの取材」イベント発生
- スマホ画面のUIで表示するとリアリティが出る

## G. 実装優先度の仮置き

```
優先高（既存の拡張）
├── 目立ち度 / ストレス パラメータの追加
├── エリア移動の「判断」化（今日どこへ行く？）
├── 初回体験コレクションの記録機能
└── エンディングのリザルト画面

優先中（リプレイ性）
├── 成長タイプ選択・アンロック
└── フレーバー分岐エンディング

優先低（ポリッシュ・追加要素）
├── 特注グッズシステム
├── 記念写真UI
└── ミニゲーム的ギミック
```
