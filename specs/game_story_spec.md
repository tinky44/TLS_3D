# ゲーム仕様：長身少女シミュレーター (Tall Life Simulator)

## 1. ゲーム概要と目的

**ジャンル**：育成・観察型シミュレーションゲーム

「普通の世界に存在する、規格外に大きな女の子」の日常を観察するシミュレーター。
プレイヤーはキャラクターを直接操作して何かを成し遂げるのではなく、キャラクターが **現実スケールのオブジェクト（ドア、机など）の中でどのように見え、どのように葛藤するかを「眺め、比較し、記録する」** ことを楽しむ。
フルアニメーションではなく「立ち絵とオブジェクトのサイズ比較＋テキスト」を中心に表現することで、低コストで実装可能かつフェティッシュな欲求を的確に満たす。

---

## 2. キャラクター作成（ゲーム開始時）

プレイヤーはゲームを始める際、キャラクターの設定を自由に選択できる。**「必ず赤ちゃんから始まる」のではなく、好きな時期からプレイスタイルに合わせて始められる（王道ライフシミュレーションの手法）。**

### ① 開始時期（年齢・学年）の選択
- 🟡 **保育園から** (3歳〜) : 先生より大きくなる過程からじっくり見たい人向け
- 🟢 **小学校から** (6歳〜) : 毎年の身体測定や学校の机との摩擦を楽しみたい人向け
- 🔵 **中学校から** (13歳〜) : 電車通学開始。急激な成長期やセーラー服から始めたい人向け
- 🟣 **高校から**   (16歳〜) : すでに2m超えの完成された巨身から始めたい人向け

### ② 初期身長とプロポーションの入力
開始時期の平均身長をベースにしつつ、プレイヤーが任意の「初期身長」と「頭身」を入力・設定可能。

### ③ 成長パターンの選択（リプレイ性の確保）
キャラ作成時に、今後の「成長タイプ」を選ぶ。いつ・どれくらい伸びるかが変わる。

- 🌱 **[じわじわ型]** : 毎月少しずつ伸びる。最終身長は190〜210cm
- 🌿 **[急成長型]** : ある時期（中学など）に一気に伸びる。最終200〜250cm
- 🌳 **[止まらない型]** : 成長期が終わらない。どこまで伸びるか分からない…
- 🎲 **[ランダム型]** : いつ・どれだけ伸びるか予測不能

### ④ 外見設定
髪型、開始時期に応じた服（私服・制服など）の設定。

## 3. ゲームの基本サイクル（コアループ）

**本ゲームには「習い事に行く」「休む」などの日々の行動を選択する要素（スケジュール管理）は存在しない。** シミュレーターとしての純度を保つため、徹底的に「時間を進めて観察する」箱庭的なプレイスタイルに特化する。

1. **時間進行ボタンのクリック**
   - 画面端にある「1ヶ月進める」などのボタンを押すだけで時間が進む。
2. **自動的な身長判定**
   - 時間が進むと裏で身長がスッと伸びる（成長パターンに基づく）。
3. **自由なステージ観察**
   - メニューから「家」「教室」など好きなステージにワンタッチで切り替え、オブジェクトと並べて比較コメントを楽しむ。
4. **イベント発生**
   - 時間の進行や規定の身長に達した際に「身体測定」や「マイルストーン通知」が自動発生する。

## 4. ステージとオブジェクト構成

詳細は「[ステージ設計書](stage_design.md)」を参照。
「場所 × 年齢」の組み合わせで構成され、選択したキャラクターの年齢に応じて順次解放される。

### 🏠 家（全年齢共通・不変の基準点）
- ドア (200cm) / シャワーヘッド (190cm) / レンジフード (170cm) / シンク (85cm) / 鏡

### 🏫 学校（教室・校庭／年齢でオブジェクトが変化）
- パラメータの変化：天井高・机のサイズ(JIS規格)・遊具(鉄棒→バスケゴール)・黒板

### 🏥 保健室（身体測定イベント専用）
- 160cm固定の保健室の先生、身長計、体重計

### 🏙️ 街・駅（移動路＆通学路）
- ポスト / 自販機 (183cm) / 信号機 / 電車ドア (180cm) / 改札 (100cm) / つり革

## 5. コアシステム・UI

### 📏 比較モード（日常の摩擦）
ステージ内でキャラを特定のオブジェクトの横に立たせると、**現在の身長とオブジェクトの高さの「差分」**、さらに **身長閾値に応じた「キャラクターの呟き（コメント）」** がUIとして表示される。
（例：ドア(200cm)に対しキャラが195cmの場合「頭すれすれ…これが私の日常」）

## 6. エンディングとクリア後要素

### 🎓 エンディング（高校卒業）
ゲームの区切りは **「18歳の3月（高校卒業）」** とする。
18歳の3月を超えようとするとエンディングイベントが発生する。
- 最終的な身長、成長グラフ、特定のオブジェクト（ドアなど）との最終比較画像が1枚のリザルトレポートとして表示される。
- キャラクターは「完成データ」として殿堂入り（アルバムに記録）し、いつでも過去の姿を眺められるようになる。

### ♾️ エンドレス・エクストラモード（クリア後）
限界を超えた成長を見届けたいフェティッシュなプレイヤー向けのモード。
- 高校卒業後も「それでも観察を続ける」という選択肢を選ぶと突入。
- 年齢や学年はもう進まない・変化しないが、ひたすら「時間を進める（身長を伸ばす）」ボタンを押し続けることができる。
- 250cm、300cmと、家の天井や街のオブジェクトを突き抜けて成長し続ける姿を自由に観察できる。
