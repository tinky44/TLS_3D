# ゲーム仕様：長身少女シミュレーター (Tall Life Simulator)

## 1. ゲーム概要と目的

**ジャンル**：物理サンドボックス型・日常ライフシミュレーター

「普通の世界に存在する、規格外に大きな女の子」の日常を**プレイヤー自身の手で操作して体感する**シミュレーター。
単に数値を眺めるだけのツール（シュミレーター）ではなく、プレイヤーがキャラクターを動かし、2Dの家や街、学校を自由に歩き回ることで、サイズの不一致から生じる**「物理的な不便さ」「NPC（モブキャラ）のリアクション」、そして「プレイヤーの行動で起きる予期せぬカオス（トラブル）」**を楽しむ。
『サクラスクールシミュレーター』のような「能動的な遊び場（サンドボックス）」としてのゲーム性を目指す。

---

## 2. キャラクター作成（ゲーム開始時）

プレイヤーはゲームを始める際、キャラクターの設定を自由に選択できる。「赤ちゃんから始まる」制約をなくし、好きな時期から始められる。

### ① 開始時期（年齢・学年）の選択
- 🟡 **保育園から** (3歳〜) : 先生より大きくなる過程からじっくり見たい人向け
- 🟢 **小学校から** (6歳〜) : 毎年の身体測定や学校の机との摩擦を楽しみたい人向け
- 🔵 **中学校から** (13歳〜) : 制服姿での電車通学や急激な成長期から始めたい人向け
- 🟣 **高校から**   (16歳〜) : すでに2m超えの完成された巨身から始めたい人向け

### ② 初期身長と成長パターンの設定
開始時期に応じた平均身長をベースにしつつ、任意の「初期身長」を設定可能。
また、今後の「成長タイプ」を選ぶことでリプレイ性を確保する。
- 🌱 **[じわじわ型]** / 🌿 **[急成長型]** / 🌳 **[止まらない型]** / 🎲 **[ランダム型]**

## 3. ゲームの基本サイクル（コアループ）

単なる「時間進行ボタン」を押す作業ではなく、**「生活すること」で時間が進む**アクション性の高いサイクルとする。

1. **自由探索とカオス**（昼）
   - プレイヤーはキャラを操作して、家、街、学校を自由に歩き回る。
   - オブジェクトを押しのけたり、NPCと絡んだり、物理的なサイズ差を利用したイタズラやハプニングを起こす。
2. **睡眠による時間スキップ**（夜）
   - 時間を進めたい場合は、自分の家の「ベッド」にアクセスして「寝る」を選択する（TODO 検討中：1ヶ月や半年スキップなど選択可能）。
3. **朝の驚き（成長の実感）**
   - ベッドから起き上がると、設定した成長パターンに基づき**裏で身長がスッと伸びている**。
   - 「昨日まで通れていた自室のドアに、今日は頭がぶつかる！」という身体的変化を、プレイヤー自身の操作の違和感としてダイレクトに体感する。
4. **イベントの発生**
   - 学校でNPCの「身体測定」イベントに参加したり、新たなオブジェクトの破壊（干渉）が可能になったりする。

## 4. サンドボックス要素とゲーム性（能動的な遊び）

フェティッシュな欲求を「遊び」に昇華するため、以下のインタラクションを実装する。

### 物理干渉と破壊（カオス要素）
キャラクターのサイズ（当たり判定と質量）が大きくなることで、世界に干渉する。
- **オブジェクトの散乱**: 普通に歩いているだけで、家の中のイスやゴミ箱、街の看板などのRigidBody（物理オブジェクト）を蹴飛ばし、ひっくり返してしまう。
- **建物の破壊的干渉**: 2m状態で普通のドアを強引にジャンプしてくぐろうとすると、頭をぶつけて画面が揺れる、または天井のチリが落ちるなどの演出。
- **マクロ（巨視）な視点**: 小さい机や低い手すりを「飛び越える」などのアクションが可能になる。

### NPC（モブキャラ）との人間関係・リアクション
街や教室にいるNPCが、キャラクターのサイズに応じて動的に反応を変える。
- **驚きのリアクション**: 身長が190cmや200cmを超えると、近づくだけでNPCが「えっ、でかっ…！」「見上げてしまう…」と吹き出し（フキダシ）を出したり、道を譲るように避けたりする。
- **アクションの変化**: スケール差が一定以上になると、NPCの「頭を撫でる」アクションが可能になったり、逆に大きすぎるプレイヤーを見てNPCがビビって逃げ出したりする。

## 6. エンディングとクリア後要素

### 🎓 エンディング（高校卒業）
ゲームの一応の区切りは **「18歳の3月（高校卒業）」** とする。
18歳の3月を超えてベッドで寝ようとするとエンディングイベントが発生。
- 最終的な身長、成長グラフ、街やNPCとの思い出（最終比較画像）がリザルトレポートとして表示される。
- キャラクターは「完成データ」としてアルバムに記録される。

### ♾️ エンドレス・エクストラモード（クリア後）
限界を超えた成長を見届け、世界をカオスに陥れたいプレイヤー向けのモード。
- 高校卒業後も「そのままの生活を続ける」選択を選ぶと突入。
- 年齢や学年は進まないが、アイテムや睡眠による「身長の成長」だけは無限に続く。
- 250cm、300cmと、家の天井や街のオブジェクトを突き抜けて物理法則を破壊しながら歩き回る姿を自由に楽しめる。
