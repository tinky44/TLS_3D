
# ゲーム仕様

## ゲーム性

ジャンル：シミュレーションゲーム

## キャラクター作成

キャラクターはユーザが自由に作成できる
身長と頭身を入力できる
髪型なども設定できる。

## タイトル画面

作成したキャラクターごとにセーブが可能。
そのキャラクターに応じて、保育園から高校までの人生を体験できる

## ステージ構成

詳細は [ステージ設計書](stage_design.md) を参照。

それぞれのステージには、街（道路）を通ることで移動できる。街にも様々なオブジェクトが配置されている。
年齢によって行けるステージが解放される。

- 🏠 家（全年齢共通）
- 🏫 学校・教室（保育園 → 小学校 → 中学校 → 高校で切替）
- 🏫 学校・校庭（年齢で遊具が変化）
- 🏥 保健室（身体測定イベント専用）
- 🏙️ 街（全年齢共通・移動路）
- 🚉 駅（中学以降解放）
