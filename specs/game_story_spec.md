# ゲーム仕様：長身少女シミュレーター (Tall Life Simulator)

## 1. ゲーム概要と目的

**ジャンル**：物理サンドボックス型・日常ライフシミュレーター

「普通の世界に存在する、規格外に大きな女の子」の日常を**プレイヤー自身の手で操作して体感する**シミュレーター。
単に数値を眺めるだけのツール（シュミレーター）ではなく、プレイヤーがキャラクターを動かし、2Dの家や街、学校を自由に歩き回ることで、サイズの不一致から生じる**「物理的な不便さ」「NPC（モブキャラ）のリアクション」、そして「プレイヤーの行動で起きる予期せぬカオス」**を楽しむ。
能動的な遊び（サンドボックス）に加え、自分の意志とは無関係に「大きくなってしまう」ことによる**受動的なドラマ（振り回される体験）**を物語の核とする。

## 2. キャラクター作成（ゲーム開始時）

プレイヤーはゲームを始める際、キャラクターの設定を自由に選択できる。

### ① 開始時期（年齢・学年）の選択
- 🟡 **保育園から** (3歳〜) : 先生より大きくなる過程からじっくり見たい人向け
- 🟢 **小学校から** (6歳〜) : 毎年の身体測定や学校の机との摩擦を楽しみたい人向け
- 🔵 **中学校から** (13歳〜) : 制服姿での電車通学や急激な成長期から始めたい人向け
- 🟣 **高校から**   (16歳〜) : すでに2m超えの完成された巨身から始めたい人向け

### ② 初期身長と成長パターンの設定
開始時期に応じた平均身長をベースにしつつ、任意の「初期身長」を設定可能。
- 🌱 **[じわじわ型]** / 🌿 **[急成長型]** / 🌳 **[止まらない型]** / 🎲 **[ランダム型]**

## 3. ゲームの基本サイクル（コアループ）

「生活すること」で時間が進み、**「身体の裏切り」**による変化を受け入れていくサイクル。

1. **カレンダー進行と日常探索**（昼）
   - 日付（月・学期）という外的な時間軸に沿って生活する。
   - ステージを自由に歩き回り、オブジェクトやNPCと干渉する。
2. **睡眠による成長進行**（夜）
   - ベッドで「寝る」ことで日付が更新される。
   - 睡眠中、設定した成長パターンに基づき**裏で身長が成長する**。
3. **朝の衝撃と受動的イベント**
   - 起き上がった瞬間、「昨日まで通れたドアに頭がぶつかる」といった身体的変化を操作の違和感として体感する。
   - 身長が特定の閾値を超えた場合、強制的に**「身体の裏切りイベント（服が破れる等）」**が発生する。
4. **イベントとフィードバック**
   - 学校行事（身体測定、体育祭など）が発生し、身長に応じた役割を押し付けられる。
   - 出来事に対して「自信」か「コンプレックス」かの感情を選択し、主人公の独白（トーン）を形作る。

## 4. ナラティブ・イベントシステム（能動と受動の融合）

### ① 身体の裏切り（成長閾値イベント）
単なる数値の増加ではなく、不便さが「向こうから」やってくる体験。
- **服・靴の限界破綻**: 「パジャマの袖が裂ける」「登校用の靴が入らない」といったイベント。不格好な格好で登校し、他者の視線を浴びる。
- **強制呼び出し**: 一定身長を超えると、先生から「保健室へ来なさい」と呼び出され、特注の什器や健康相談のノベルパートが発生。

### ② 社会的役割（逃れられない行事）
身長ゆえに特定の役割を押し付けられる受動的なストーリー。
- **運動会の旗手・文化祭の力仕事**: 高身長を頼りにされ、自由行動が制限されるイベント。
- **集合写真の悲哀**: 記念撮影で必ず「最後列の端」に配置され、頭が見切れる演出（フォトモード連動）。

### ③ 環境トラップ（気象・密集）
天候や人口密度が物理的な「障害」へと変貌する。
- **雨の日の傘**: 街ステージでNPCの傘の先がちょうど顔の高さに来るため、回避や屈み歩行を強いられる。
- **人混みの視線**: 繁華街などの人混みで、頭一つ飛び抜けているゆえに常に視線を浴び続け、移動に精神的・物理的コストがかかる。

## 5. サンドボックス要素とインタラクション

### 物理干渉とカオス
- **オブジェクトの散乱**: 普通に歩くだけでイスやゴミ箱を蹴飛ばしてしまう。
- **破壊的干渉**: ドアを強引にジャンプでくぐろうとすると天井からチリが落ち、画面が揺れる。
- **操作の重み**: 極端な高身長（例：220cm〜）では、屈み動作や立ち上がりにわずかな「ディレイ（慣性）」が発生し、巨体の制御の難しさを体感させる。

### レピュテーション（評判）システム
プレイヤーのこれまでの行動がNPCの接近に影響する。
- **「取ってあげて」の列**: 高いところの物を取ってあげる評判が良いと、校庭を歩くだけでNPCに足止めされ、お願い事をされる。
- **「畏怖」と忌避**: 物を壊しすぎると、NPCが遠巻きにヒソヒソ話をしたり、近づくと逃げ出したりする。
