# 髪型描画システム (Hair Drawing System)

## 概要
`CharacterDrawer.gd` 内の `_draw_hair` メソッドを中心に実装されている髪型の描画ロジックについて解説します。
髪の描画は、Zオーダー（描画順）を意識して、奥（顔の背面）から手前（顔の前面）へと順に複数の図形を重ねることで、立体感とキャラクター特有のシルエット（ストレートヘアなど）を表現しています。

## 描画順序 (Z-Order)
基本的な描画のプロセス（背面に描くものから、手前に描くものへの順番）は以下の通りです。

1. **後ろ髪 (Back Hair)**: 顔の裏側に配置されるベースの髪。
2. **顔 (Face)**: 肌色のベースとなる円。
3. **サイドヘア (Side Hair)**: 顔の両脇を覆うように垂れ下がる髪（現在は正面のみ）。
4. **前髪 (Bangs)**: 額にかかる一番手前の髪。

---

## ビュー別の描画仕様とASCIIアート

### 正面 (Front View)
正面ビューでは、手描きイラストの「顔をコの字型に包み込むようなストレートヘア」のシルエットを再現するため、4つの層に分けて図形を組み合わせています。

```text
  [1. 後ろ髪: ドーム (ellipse) + ベース (polygon)]
  顔の背面に、頭頂部の丸みと、下部へ直線的に落ちるベースを描画します。
      .--------.
    /            \
   |              |
   |              |
   |              |
   +--------------+ (ロングの場合は下まで伸びる)

  [2. 顔 (ellipse)]
  肌色の顔を重ねます。この段階ではまだ顔の側面が丸出しです。
      .-------
    /  .----.  \
   |  / ・ ・\  |
   |  \      /  |
   |   `----'   |
   +------------+

  [3. サイドヘア: (polygon)]
  顔の左右の端を隠すように、垂直な四角形の髪を手前に重ねます。
  これによりイラストのような、直線で顔を挟む「コの字」のシルエットが生まれます。
      .--------_
    /|  .----. |\
   | | / ・ ・\| |
   | | \      /| |
   | |  `----' | |
   +-------------+

  [4. 前髪: (polygon)]
  額の上に非対称左側に分け目がある形状）のポリゴンを被せます。
      .--------_
    /|  .\/---. |\
   | | / ・ ・\| |
   | | \      /| |
   | |  `----' | |
   +-------------+
```

### 側面 (Side View)
側面ビューでは、従来の楕円のみのアプローチを改善し、後頭部の丸みを持たせつつ下へストレートに落ちるイラスト風のシルエットで描画します。

```text
  [顔を中心にした構成]
  ・後ろ髪: 後頭部のボリュームを作る楕円 (ellipse) + 下へ落ちる矩形ポリゴン (polygon)
  ・前髪: 頭頂部から前方へ突き出す三角形 (polygon)

    .------.
  ///\======|
 //// |=====|
|   . |=====|
 \___/======|
     |======|
     `------'
     |======| (ロングの場合はさらに下へ伸びる)
     |======|
     +------+
```

### 背面 (Back View)
背面ビューは顔が見えないため、構成要素が最も少なくなります。

```text
  [ショートヘアの場合]
  頭を全体的に覆う円 (ellipse) のみ。
        .----.
       /      \
      |        |
       \      /
        `----'

  [ロングヘアの場合]
  頭の円の下に、肩へ向かって広がる、または垂れる台形 (trapezoid) を追加。
        .----.
       /      \
      |        |
      |        |
      +--------+
```

## パラメータとカスタマイズ
髪の形状や長さは、以下の変数（パラメータ）に依存して動的に変化します。

- **`hair_style`**: `"short"` や `"long"` などの指定。これによって `hair_bottom_y` （髪の下端のY座標）が大きく変わり、ロングヘアの場合は各ビューで髪のポリゴンが下方へ長く伸びます。
- **`head_r` (頭の半径)**: 物理的なキャラクターの身長設定(`m`)から算出される頭のサイズ。このサイズを基準に、`hr * 1.35` (髪の外枠の幅) のように、相対的なスケールで髪のボリュームが計算されます。
- **`hair_color`**: `appearance.hair_color` から取得されるカラーコード。現在はシルエット全体がこの1色でベタ塗りされます。
