# キャラクター描画システム (Character Drawing System)

## 概要

キャラクター描画は `CharacterDrawer.gd` と `CharacterDrawUtils.gd` にロジックが集約されており、「高さや座標の計算（IK等）」「描画ロジック」「基本図形の描画」という要素に分割されています。
これにより、開発者側でキャラクターのベースとなる形（頭を円にするか、胴体を矩形にするかなど）を定義・カスタマイズしやすくなっています。

## アーキテクチャ構成

1. **`CharacterPoseCalculator.gd`**:
   歩行フェーズやキャラクター全体のプロポーション(`m`)データを元に、各関節の座標(`cx`, `hy`等)や角度情報を計算します。
2. **`CharacterDrawUtils.gd`**:
   実際のキャンバスへの描画（`draw_polygon`, `draw_circle`等）を担当する純粋なユーティリティです。
3. **`CharacterDrawer.gd`**:
   骨格データを受け取り、設定された描画形状 (`part_shapes`) に従ってパーツごとの色・形・位置を組み合わせて描画を実行します。

## パーツ別の描画形状仕様

現在のキャラクター描画における、各パーツの形状仕様は以下のようになっています。

### 基本設定 (`part_shapes`)
`CharacterDrawer.gd` 内で、各パーツの基本図形が定義されています。

```gdscript
var part_shapes = {
	"head": "ellipse",
	"torso_lower": "trapezoid", 
	"torso_upper": "trapezoid",
	"torso_front_lower": "pentagon",
	"torso_front_upper": "rect",
	"limb": "stick",
	"neck": "limb",
}
```

### 頭部 (Head)
- 形状: 基本的に **楕円 (`ellipse`)** または矩形 (`rect`)。
- **顔パーツ**:
  - 正面/背面: 目は小さな円(`#333333`)で表現。口は複数の線分を用いた曲線で描画。
  - 側面: 目は前方側に配置された小さな円。口は短い直線で描画。

```text
  [楕円 (ellipse)]
       .--.
     (      )
      `--'
```

### 胴体 (Torso)
向きによって描画ロジックが異なります。

#### 正面・背面
- **上部胴体 (`torso_front_upper`)**: **四角形 (`rect`)**。肩 (`sx`, `sy`) から腰 (`wx`, `wy`) までを描画。
- **下部胴体 (`torso_front_lower`)**: **5角形 (`pentagon`)**。腰から股 (`cx`, `cy`) までを描画し、下部中央に向かって三角形が突き出た形状（股の表現）。

```text
  [上部: 四角形 (rect)]
    +--------+  <-- 肩 (sx, sy)
    |        |
    |        |
    +--------+  <-- 腰 (wx, wy)

  [下部: 5角形 (pentagon)]
    +--------+  <-- 腰 (wx, wy)
    |        |
    |        |
     \      /   <-- 側面コーナー
      \    /
       \  /
        \/      <-- 股下 (cx, cy)
```

#### 側面
- 前面と背面で異なる輪郭を持つため、専用の**5角形**（`draw_side_torso`関数）を用いて一体で描画されます。
- **厚み**: 全体を通して一定（頭の横幅 × 0.85）。
- **背面**: 直線的（一直線に肩後端から股後端まで垂直に下りる線）。
- **前面**: 上部（肩前端から乳首の高さまで）が斜めにカットされ、それ以下の部分は垂直に下りる構造。
- 関節の位置づけとして「関節の左端(後端) = 頭部中心縦軸(`hx`)」の直線上に来るように設計されています。

```text
  [側面胴体: 5角形 (side_torso)]

(背面: back_x) (前端: shoulder_front_x)
        |      \  
        |       \ 
        |        \
        |         \
        |          ● ← 乳首前端 (front_x / 折れ点)
        |          |
        |          | ← 乳首以下は垂直
        |          |
        ●──────────● ← 股 (front_x)
 (背面下端)
```

### 腕・脚 (Limb) と 首 (Neck)
- 形状: **スティック (`stick`)** (線分 ＋ 両端に関節を示す円) が基本。
- 他に `limb` (カプセル状の角丸矩形) や `rect` (矩形)、`line` (単純な線) に切り替え可能。
- **首 (`neck`)** はデフォルトで `limb` が指定されます。

```text
  [スティック (stick)]
     ( )  <-- 関節 (円)
      |
      |   <-- 骨 (太線)
      |
     ( )  <-- 関節 (円)

  [カプセル (limb)]
    .---.
    |   |
    |   |
    '---'
```

### 手足の先 (Hand / Foot)
- **手 (Hand)**: 小さな楕円形（横幅が縦幅より少し広い比率、1.4：0.9）。
- **足 (Foot)**:
  - 正面: 小さな四角形。
  - 側面: **くさび形（三角形）**。つま先が前方向を向く構造。

```text
  [足: 側面 (三角形)]
   (足首)
     +
     |\
     | \
     |  \
     +---+ (つま先)
```

## カスタマイズと拡張
新しい形状を追加したい場合は `CharacterDrawUtils.gd` に描画関数 (`draw_***`) を追加し、`CharacterDrawer.gd` の `part_shapes` で該当する描画関数が呼ばれるように分岐を追加（`elif shape == "..."`）するだけで自由に拡張可能です。
