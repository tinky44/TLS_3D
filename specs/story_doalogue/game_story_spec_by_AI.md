# tall_life_simulator ゲームデザイン提案書（AI案）

> **前提**: このドキュメントは `misc/tinky44_analysis.md` の作品分析と `specs/game_story_spec.md` の仕様を踏まえ、
> フェティッシュに刺さりつつ、**Godot 4.x の個人開発で実装可能**なゲームデザインを提案するものです。

---

## 現状の課題整理

| 課題                 | 詳細                                                     |
| -------------------- | -------------------------------------------------------- |
| ゲーム性がない       | キャラを操作してドアをくぐらせるだけ                     |
| イベントアニメが重い | 学校行事などのイベントシーンをアニメで作るのは工数が膨大 |
| ノベルゲーム化の危険 | テキストだけに頼ると、小説サイトと差別化できない         |

### 既にある強み

| 資産                     | 内容                                               |
| ------------------------ | -------------------------------------------------- |
| キャラクター描画システム | 身長・頭身を反映して動的に描画可能                 |
| ステージ描画             | StageBuilder で家・オブジェクト配置済み            |
| 比較オブジェクト         | ドア・机・鉄棒など、現実スケールの建具が実装(予定) |
| キャラクター作成         | 身長・頭身をユーザーが自由設定可能                 |

---

## コンセプト：「眺めて・比べて・育てる」シミュレーター

### 核心的な問い

> **このゲームでしか得られない体験は何か？**

答え：**「自分が設定した（あるいは育てた）キャラクターが、現実スケールのオブジェクトの中でどう見えるかを眺める」体験。**

小説では「想像」するしかなかったものを、**実際に目で見て確認できる**。これが最大の差別化ポイント。

## 提案1：コアループ —「成長 → 比較 → 記録」サイクル

### ゲームの基本ループ

```
┌─────────────────────────────────────────┐
│                                         │
│   時間経過（月齢進行）                   │
│        ↓                                │
│   身長が少し伸びる（自動 or イベント）    │
│        ↓                                │
│   ステージを自由に散歩する               │
│   （オブジェクトとの比較を楽しむ）        │
│        ↓                                │
│   身体測定イベント（定期）               │
│   （数値をじっくり見せる）               │
│        ↓                                │
│   成長記録アルバムに自動保存             │
│        ↓                                │
│   （繰り返し）                           │
│                                         │
└─────────────────────────────────────────┘
```

**ポイント：**
- プレイヤーが「操作して何かを達成する」ゲームではなく、**「変化を眺めて楽しむ」観察型ゲーム**
- 本質は「盆栽」「アクアリウム」「アイドルマスター」型の**育成観察**
- tinky44 の嗜好分析から導かれた「成長プロセスへの執着」「測定の儀式」にピッタリ

## 提案2：「比較モード」— フェティッシュの核心

### 概要

ステージ内でキャラクターをオブジェクトの横に立たせると、**自動的にサイズ比較演出**が入る。

### 実装イメージ（低コスト）

```
┌──────────────────────────────────────┐
│                                      │
│   [キャラ]   [ドア枠]                │
│      ↕ 身長差表示                    │
│                                      │
│   ┌────────────────────────┐         │
│   │  彼女の身長: 192.3cm   │         │
│   │  ドアの高さ: 200.0cm   │         │
│   │  残り余裕:    7.7cm    │         │
│   │                        │         │
│   │  💬 まだ頭は当たらない  │         │
│   │     けど、つま先立ちは  │         │
│   │     もう無理かも…      │         │
│   └────────────────────────┘         │
│                                      │
└──────────────────────────────────────┘
```

**各オブジェクトごとにコメントテーブルを用意するだけで、ノベルゲームに頼らずに物語性を出せる。**

### コメントのパターン例

| オブジェクト             | 身長閾値   | コメント（キャラの独白）                       |
| ------------------------ | ---------- | ---------------------------------------------- |
| ドア (200cm)             | ＜170cm    | 「普通のドアだなぁ」                           |
|                          | 170〜190cm | 「ちょっと気をつけないとね」                   |
|                          | 190〜200cm | 「頭すれすれ……これが私の日常」                 |
|                          | 200〜210cm | 「かがまないと通れなくなった」                 |
|                          | ＞210cm    | 「もう腰を折らないと通れない。毎日これか……」   |
| バスケットゴール (305cm) | ＜170cm    | 「あんな高いところ、ジャンプしても届かない」   |
|                          | 250〜305cm | 「あれ？　手を伸ばしたら届きそう……？」         |
|                          | ＞305cm    | 「リングより背が高い。もうバスケはできないね」 |
| 机（JIS 6号: 76cm）      | ＜160cm    | 「ちょうどいい高さの机」                       |
|                          | 180〜200cm | 「低い……膝が入らなくて座れない」               |
|                          | ＞200cm    | 「もはや子ども用のテーブルにしか見えない」     |

**この仕組みなら：**
- ✅ アニメーション不要（既存のキャラ描画＋テキスト表示のみ）
- ✅ オブジェクトを増やすだけでコンテンツが増える
- ✅ 「身長が変わるたびに新しいコメントが読める」→ リプレイ動機
- ✅ フェティッシュの核心（「○○cmだと△△がこうなる」）を直撃

## 提案3：「成長曲線」システム — 時間経過のドキドキ

### 身長成長パターンの選択

キャラ作成時に「成長タイプ」を選べるようにする。

```
┌──────────────────────────────────────────────┐
│  成長タイプを選んでください                    │
│                                               │
│  🌱 [じわじわ型]                              │
│     毎月少しずつ伸びる。最終身長は190〜210cm   │
│                                               │
│  🌿 [急成長型]                                │
│     ある時期に一気に伸びる。最終200〜250cm     │
│                                               │
│  🌳 [止まらない型]                            │
│     成長期が終わらない。どこまで伸びるか       │
│     分からない…                              │
│                                               │
│  🎲 [ランダム型]                              │
│     いつ・どれだけ伸びるか予測不能             │
│                                               │
└──────────────────────────────────────────────┘
```

**これが面白い理由：**
- tinky44 作品の核心「成長が止まらない不安と興奮」をゲーム体験に変換
- 「次の月にはどれだけ伸びているだろう？」という**ワクワク感**
- 同じゲームでも成長タイプによって**全く違う体験**になる → 周回プレイ動機

## 提案4：「身体測定イベント」— フェティッシュの頂点

### 定期的な身体測定

学校ステージでは学期ごと（年3回）、家ステージでは毎月、身体測定ができる。

```
╔══════════════════════════════════════╗
║         🏥 身体測定結果              ║
║                                      ║
║  名前：高野 美咲（12歳・小学6年）   ║
║                                      ║
║  ┌────────────────────────────┐      ║
║  │  身長：  178.4 cm          │      ║
║  │  前回比：+3.2 cm（1ヶ月）  │      ║
║  │  成長速度：3.2 cm/月       │      ║
║  │                            │      ║
║  │  ⚡ 成長加速中！            │      ║
║  └────────────────────────────┘      ║
║                                      ║
║  同学年 平均身長：148.3 cm           ║
║  差：    +30.1cm（学年1位）          ║
║                                      ║
║  💬「え、また伸びてる……？            ║
║     先月測ったばかりなのに」         ║
║                                      ║
║        [閉じる]  [成長グラフ]        ║
╚══════════════════════════════════════╝
```

### 成長グラフ機能

```
cm
200 ┤                              ╱
190 ┤                           ╱ 
180 ┤                        ╱    ← 今ここ！
170 ┤                     ╱
160 ┤                  ╱ ← 急に伸び始めた
150 ┤              ╱
140 ┤          ╱
130 ┤      ╱
120 ┤   ╱
    └──────────────────────────────
     4歳  6歳  8歳  10歳  12歳

     --- 平均身長  ─── このキャラ
```

**フェティッシュに刺さるポイント：**
- 「+○○cm」という数値の直接的な快感
- 「学年平均との差」がどんどん広がる感覚
- グラフで「異常な成長曲線」が視覚化される
- すべて**既存の描画システムとテキストで実装可能**

## 提案5：「マイルストーン」システム — 達成の喜び

### 身長がある閾値を超えると「マイルストーン通知」が出る

```
🎉 マイルストーン達成！

   「170cmを超えました」
   → 日本人成人男性の平均身長(170.7cm)を超えています
   
   🔓 新しいコメントがアンロックされました（3件）
```

| マイルストーン | 意味                         | アンロック内容                   |
| -------------- | ---------------------------- | -------------------------------- |
| 158.0cm        | 日本人成人女性平均           | 比較コメント                     |
| 170.7cm        | 日本人成人男性平均           | 比較コメント + 街の人NPCとの対比 |
| 180.0cm        | 長身の壁                     | 「ドアに注意」系コメント         |
| 190.0cm        | 日常が困難に                 | 交通機関系コメント               |
| 200.0cm        | ドア枠超え                   | ドア通過アニメが「屈み」に変化   |
| 210.0cm        | 自動販売機のボタン全押し可能 | 自販機イベント                   |
| 240.0cm        | 一般住宅の天井高             | 家で頭がつかえる                 |
| 260.0cm        | ロバート・ワドロー超え       | 歴代最高記録のテキスト           |
| 305.0cm        | バスケゴール                 | 特殊イベント                     |

**これが効く理由：**
- **「次は何cmで何が起きるんだろう？」** という期待感で進行動機が生まれる
- オブジェクト追加 = コンテンツ追加、という**スケーラブルな設計**
- フェティッシュの快感ツボ「あの身長になったら○○が□□になる」を体系的に網羅

## 提案6：「朝の儀式」— 日常ルーティンの映像的リッチ化

### 低コストで映像的な「日常演出」

毎日（ゲーム内1日の開始）に短い「朝のルーティン」を見せる。
**アニメーション不要で、既存の描画+ステージシステムで実現可能。**

```
【朝の流れ（自動再生）】

1. 目覚め → キャラがベッドの横に立つ（ベッドとの比較）
2. 洗面所 → シンクの前に立つ（鏡=身長メーター表示）
3. シャワー → シャワーヘッドとの比較
4. 着替え → ドア枠を通過する
5. 朝食 → キッチンカウンター・椅子との比較

→ 各シーンで「その日の身長」に応じたコメントが表示される
```

**これが最小コストで最大効果になる理由：**
- すべて「キャラをオブジェクト横に立たせる」+ テキスト表示
- **毎朝の繰り返し**だから、身長変化に気づきやすい（「あれ、昨日より…？」）
- tinky44作品で頻出する「日常描写」を、ゲームとして自然に体験

## 提案7：「年齢別ライフイベント」テキストカード

### フルアニメの代わりに「テキスト+比較シーン」で表現

```
╔═══════════════════════════════════════════════╗
║  📅 4月 — 入学式                              ║
║                                               ║
║  💬「新しい制服が届いた。                      ║
║     特注サイズ。袖を通すと、                   ║
║     やっぱり丈が少し短い気がする。             ║
║                                               ║
║     教室のドアをくぐるとき、                   ║
║     少し頭を下げた。                           ║
║     誰かがヒソヒソ話していた。                 ║
║     もう慣れた。」                             ║
║                                               ║
║  [比較シーンを見る] ← ここで既存描画システム    ║
║                                               ║
╚═══════════════════════════════════════════════╝
```

### 年齢別のイベント例

| 年齢  | イベント                     | 比較対象             |
| ----- | ---------------------------- | -------------------- |
| 4-5歳 | 保育園入園                   | 先生（160cm）と並ぶ  |
| 6歳   | 小学校入学                   | ランドセル・同級生   |
| 8歳   | 身体測定で保健室の身長計超え | 身長計（200cm）      |
| 10歳  | 机に座れなくなり特注品が届く | JIS机比較            |
| 12歳  | 修学旅行のバス問題           | バスの天井（180cm）  |
| 13歳  | 中学入学・制服がない         | ドアとの比較         |
| 15歳  | 高校入学・バスケ部に誘われる | バスケゴール         |
| 16歳  | 電車通学が困難に             | 自動改札・電車の天井 |

**ポイント：**
- テキストカードは**jsonデータとして外部管理**すれば追加が容易
- 「比較シーンを見る」ボタンで既存のステージ描画に飛ばすだけ
- フルアニメ不要で**物語性**を出せる
- 身長に応じて**動的にテキストが変わる**（同じ入学式でも170cmと200cmで内容が違う）

## 提案8：フォトモード — ユーザー生成コンテンツ

### スクリーンショット＋共有機能

```
📸 フォトモード
  
  ・キャラを好きな位置に配置

  ・ズーム / アングル調整

→ 「見て、うちの子がこんなに大きくなった」という共有欲
```

**フェティッシュコミュニティでの拡散力が高い。**

## 設計思想まとめ

### やらないこと
- ❌ フルアニメーションのイベントシーン
- ❌ 複雑な選択肢分岐（ノベルゲーム化）
- ❌ アクション操作の精密さを要求するゲーム性

### やること
- ✅ **「キャラをオブジェクトの横に並べる」** を最大限活かす
- ✅ **数値変化（身長の成長）に感情を乗せる** テキスト演出
- ✅ **時間経過 × 比較のバリエーション** でリプレイ性を確保
- ✅ **データ駆動**（jsonでイベント・コメント管理）で拡張容易に

### 一文でまとめると

> **「成長する少女を、現実スケールの中で眺め続ける箱庭」**

それが、tinky44 の小説が描いてきた体験を、唯一ゲームとして再現できる形。
