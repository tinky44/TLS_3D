# キャラクターポーズ仕様書 (Character Poses Specification)

本ドキュメントでは、シミュレーター内のキャラクターが取る4種類の基本ポーズ（`pose`）における骨格の計算ロジックと関節角度を定義します。

## 0. 共通計算ルール

座標は、キャラクターの足元（地面）を `y = 0.0` とし、上方向を負（`-`）とする Godot の 2D 座標系に基づきます。
すべての計算において、`p` (`CM_TO_PX`) は 1cm あたりのピクセル数を示します。

### 胴体の分割（比率）
胴体（脊椎）は、股下から肩までを「胴体長（便宜上 `m["arm"]` と同等）」とし、以下の比率で分割されます。
- **下部 (navel_l)**: へそまでの長さ（胴体長の 40%）
- **上部 (chest_l)**: 肩までの長さ（胴体長の 60%）
### 脚の分割（比率）
- **太もも (thigh_l)**: 脚の長さ (`m["leg"]`) の 55%
- **スネ (shin_l)**: 脚の長さ (`m["leg"]`) の 45%
  
---

## 1. Normal (立ち姿 / しゃがみ)

通常の直立、および障害物回避のための「しゃがみ」を含む状態です。
- **腰の位置 (y_crotch)**: 
  - 直立時: `-m["leg"] * p` (脚の長さ分、上に浮いている)
  - しゃがみ時: 脚の折り曲げ具合（`t`）に応じて地面（0.0）に近づく。
- **胴体の角度 (waist_angle)**: 
  - 直立時: `0.0` (垂直)
  - しゃがみ時: 最大 `1.3` (約74.5度) まで前傾。
- **脚の状態**:
  - 歩行中は `leg_l_angle` が `walk_amp * sin(walk_phase)` で振動。
  - しゃがみ時は膝（`knee`）が最大 `PI * 0.7` まで曲がる。
---

## 2. Taiiku Suwari (体育座り / 2キー)

体を丸めて地面に直接座るポーズです。
- **腰の位置 (y_crotch)**: `-15.0 * p` (地面から 15cm)
- **胴体の角度 (waist_angle)**: `0.3` (約17.2度。わずかに前傾)
- **脚の状態**:
  - `leg_l_angle`: `-130` (斜め上方向に太ももを上げる)
  - `knee_l`: `PI * 0.72` (膝を深く抱える)
- **腕の状態**: `arm_l_angle = -60` (膝を抱える位置)
---

## 3. Chair Sit (椅子に座る / 3キー)

椅子に座ることを想定したポーズですが、現状は「椅子がない場所での空気椅子/床座り」のような実装になっています。
- **腰の位置 (y_crotch)**: `-5.0 * p` (地面から 5cm。椅子というよりは床に近い)
- **胴体の角度 (waist_angle)**: `PI * 0.5` (90度。真横に胴体を折り曲げた状態)
- **脚の状態**:
  - `leg_l_angle`: `-90` (太ももが地面と平行)
  - `knee_l`: `PI * 0.5` (膝を直角に曲げる)
- **腕の状態**: `arm_l_angle = -30`
> [!NOTE]
> 現在の仕様では、胴体が真横に折れているため、非常に窮屈に見えます。改良案として腰を高くし、胴体を垂直に近づける必要があります。
---

## 4. Sleep (寝る・伏せる / 4キー)

最も低く伏せ、横になるポーズです。
- **腰の位置 (y_crotch)**: `-12.0 * p` (地面から 12cm)
- **胴体の角度 (waist_angle)**: `PI * 0.85` (約153度。非常に深く前屈している)
- **脚の状態**:
  - `leg_l_angle`: `-120`
  - `knee_l`: `PI * 0.65`
- **腕の状態**: `arm_l_angle = -80` (非常に深く折り畳む)
---

## 部位座標の算出式 (cx, cy を基準)

全ての座標は、算出された `cy` (`y_crotch`) を基準に、`waist_angle` を用いて計算されます。
- **へそ**: `cy - navel_l * cos(waist_angle * 0.5)`
- **肩**: `navel_y - chest_l * cos(waist_angle)`
- **首**: `sy - 2.0 * m["neck"] * p * cos(waist_angle)`
- **頭**: `ny - (head_h / 2.0) * cos(waist_angle)`
このように、胴体が曲がる（`waist_angle` が増加する）ほど、各部位の Y 座標は地面方向（下方）へシフトするように定義されています。
