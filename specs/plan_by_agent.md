## 課題：高身長時の部屋内バグ（400〜500cm+）

### 問題の整理

| 症状 | 発生条件 |
|---|---|
| 部屋内でキャラが天井/地面に埋まる | 部屋に入った後、または部屋内で身長が伸びた場合 |
| 家に入れない（扉でブロック） | 屋外→室内遷移。扉高さ固定200cm、overhead衝突判定 |
| 家の上に立ってしまう | CollisionShape位置のY計算バグ |

### 根本的な数値の問題

| ステージ | 天井高さ(cm) | 400cmキャラとの比率 |
|---|---|---|
| room / myroom | 240 | 1.67倍オーバー |
| train | 230 | 1.74倍オーバー |
| gymnasium | 400 | ちょうど（実際は超過） |

---

### 発生シナリオ

#### シナリオ1：屋外→室内遷移
- 扉のoverhead衝突判定（200cm固定）に頭が引っかかる
- → 入室ブロック（アイデアB）で対処可能

#### シナリオ2：部屋内での起床・成長イベント（入室ブロックでは防げない）
- ゲーム開始時や成長イベントで、部屋の中からキャラがスタートする
- 身長が天井を超えていても部屋内にいる状態が発生する
- → 入室ブロックだけでは解決しない。追加対策が必要

---

### アイデア一覧

#### アイデア A：ステージを身長に応じて動的スケール
部屋に入る時 or 成長イベント後に、天井高さをプレイヤー身長にあわせてスケールアップ。

```
# 例: 天井高さが240cmで身長400cmなら、ステージを縦1.67倍にスケール
stage_scale_y = max(1.0, player_height_cm / ceiling_height_cm)
```

- メリット：シナリオ1・2どちらにも対応。「狭い部屋がさらに狭く見える」演出とも一致
- デメリット：StageBuilderの生成ロジック変更が必要。背景グラフィックの歪みが出る可能性
- 実装コスト：中〜高

#### アイデア B：入室ブロック + 「頭がつかえて入れない」メッセージ
扉進入時に `player_height > door_height` をチェックしてブロック。

- メリット：実装コスト低。ゲームコンセプト（高身長の不便さ）と一致
- デメリット：**シナリオ2（部屋内起床・成長）には対応できない**
- 実装コスト：低

#### アイデア C：コリジョン計算の修正（埋まり防止）
`_update_collision()` の `collision_shape.position.y = -h_px / 2.0` を見直し、
足元が必ず地面Y=0に接するように修正。

```gdscript
# 現在（問題あり）
collision_shape.position.y = -h_px / 2.0

# 修正案
shape.height = max(40.0, h_px)
shape.radius = min(shape.radius, h_px / 2.0)
collision_shape.position.y = -h_px / 2.0  # CapsuleShape2Dは中心起点なのでこれ自体は正しい
# → 実際のバグはキャラのglobal_position.yが地面からずれている可能性を調査
```

- 実装コスト：低〜中（原因をもう少し掘り下げる必要あり）

#### アイデア D：部屋内成長時のカメラズームアウト + キャラ位置リセット（シナリオ2対策）
成長イベント後に身長 > 天井高さ の場合：
1. カメラをズームアウトして部屋全体+キャラが見えるようにする
2. キャラのY位置を `floor_y - player_height_px` に強制リセット（天井突破を防ぐ）
3. 演出として「天井に頭が当たるガツン」効果を入れる（オプション）

- メリット：シナリオ2に直接対応
- デメリット：カメラ制御が複雑になる
- 実装コスト：中

#### アイデア E：天井高さを「プレイヤーにとっての体験」で表示（視覚的ごまかし）
実際のコリジョン高さは変えずに、描画上の天井だけを上に移動させる。
数値的なリアリティより「見た目の正しさ」を優先。

- 実装コスト：低（描画オフセットのみ）
- ただし物理とのずれが残る

---

### 推奨方針（優先度順）

1. **C（コリジョン修正）** → まず「家の上に立つ」バグを潰す
2. **B（入室ブロック）** → 屋外→室内遷移のブロックで「入れない」問題を仕様化
3. **D（成長時カメラ+位置リセット）** → 部屋内起床・成長シナリオに対応

AとEは必要に応じて後回しでOK。
