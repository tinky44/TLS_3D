## 次のステップ（Next Actions）

### A. NPCと両親の身長設定の導入（Next Action）
「相対的な身長の高さ」をゲーム内で実感させるための基盤作り。

1. **両親の身長設定（キャラクリ画面）**
   - キャラクリ画面で「父親」「母親」の身長を入力またはランダム生成できるようにする。
   - これにより、主人公がどのような環境（遺伝的な期待値）で育ったか、あるいは両親よりも大きい/小さいなどの初期コンテキストを持たせる。
   - ※将来的にはこれをベースに親NPCの見た目を自動生成する。

2. **比較対象となるNPCの配置**
   - プレイヤーと比較できる「一般的な身長のNPC」をステージ上に配置する。
   - 現状の描画システム（CharacterDrawerなど）を拡張・または別ノード化して、NPCも同様の手法で（しかし固定の身長で）描画できるようにする。

### B. ステージの拡張と移動アクション（優先：高）
`stage_design.md` の構想と現在の `StageBuilder.gd` のアセットを繋げ、**家 → 街 → 学校/駅** という世界観の繋がり（シームレスな体験）を構築する。

1. **家（room）から街（outdoor）への外出**
   - リブング (`room`) の玄関ドア（`door_exit`：x:100~180 付近）の前に立った時、アクション（キー入力またはUI）で外の世界 `outdoor` ステージへ遷移できるようにする。

2. **街（outdoor）をハブとしたステージ分岐**
   - `outdoor`（街）ステージを拡張し、以下の遷移トリガー（看板やドアなど）を配置する。
     - 【左端】：家に帰る（`room` へ）
     - 【中間】：駅・電車（`train` へ）
     - 【右端】：学校（`school` へ）
   - まずは単純なUIボタンのポップアップ等で遷移できるように実装する。

3. **各ステージからの帰還**
   - `school` や `train` ステージの端に、街（`outdoor`）へ戻るためのポイント（ドアなど）を作る。

## 開発メモ

### 身体パラメータの計算式 (`Global.gd`)
- `head = height / ratio`
- `leg = height * legRatio / 100`
- `arm = height - leg - head - (neck * 2)`
- `armLength = head * 2.7`

### 屈みの二分探索 (`CharacterPoseCalculator.gd`)
目標の高さ（px）を満たす最小の `t` (ポーズパラメータ) を反復探索。
- `t` (0~1): 直立からかがみ（背中を丸める）
- `t` (1~2): 更に深く屈む（膝を曲げる）
