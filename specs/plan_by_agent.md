#### 成長システム（Growth System）の実装

##### 概要
「保健室で身長計に近づきEキーを押す → 測定イベント → 学期が進む → 身長が伸びる」という一連のサイクルを実装する。

##### 時間単位
学期（term）を基本単位とする。1年3学期制。

```
保育園(3-5歳)   → 6学期
小学校(6-12歳)  → 21学期
中学校(13-15歳) → 9学期
高校(16-18歳)   → 9学期
合計              45学期
```

##### Global.gd への追加

```gdscript
# 成長パラメータ
var age: int = 6               # 現在の年齢
var term: int = 0              # 学期番号（0-44）
var growth_factor: float = 1.0 # 成長係数（将来：キャラクリで設定）
var prev_height: float = 0.0   # 前回測定時の身長（前回比表示用）
```

##### 成長量の計算式

```gdscript
# 年齢別 基準成長量（1学期あたり cm）
static func get_base_growth(current_age: int) -> float:
    if current_age <= 5:   return 2.0   # 保育園
    elif current_age <= 9: return 1.8   # 小学校前半
    elif current_age <= 12: return 2.5  # 小学校後半（成長加速）
    elif current_age <= 15: return 3.2  # 中学校（ピーク）
    elif current_age == 16: return 2.0  # 高校1年（減速）
    else:                   return 0.8  # 高校2-3年（収束）

# 1学期の成長量 = 基準値 × 成長係数 × ランダムブレ(±30%)
func calc_growth() -> float:
    var base = get_base_growth(age)
    return base * growth_factor * randf_range(0.7, 1.3)
```

## 開発メモ

### 身体パラメータの計算式 (`Global.gd`)
- `head = height / ratio`
- `leg = height * legRatio / 100`
- `arm = height - leg - head - (neck * 2)`
- `armLength = head * 2.7`

### 屈みの二分探索 (`CharacterPoseCalculator.gd`)
目標の高さ（px）を満たす最小の `t` (ポーズパラメータ) を反復探索。
- `t` (0~1): 直立からかがみ（背中を丸める）
- `t` (1~2): 更に深く屈む（膝を曲げる）

### ステージ遷移の仕組み (`MainScene.gd`)
- `door_to_XXX` → `"XXX"` を自動解決して遷移
- 戻り口ドア `door_to_<from_stage>` の近くにスポーン
- 追加ステージは STAGES 辞書に定義するだけで自動対応
