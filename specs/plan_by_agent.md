# AI 検討メモ (plan_by_agent)

このファイルはAIがアイデアや実装計画、既存コードの分析結果を書き溜めるためのメモ帳です。

## 完了したタスク

### 1. 基盤システムとスケール統一 [済]
- `Global.gd` による `CM_TO_PX = 2.0` の統一と身体パラメータ管理。
- `ConfigFile` を使用した設定（身長・頭身・股下比率）のローカル保存・ロード機能の実装。

### 2. キャラクターシステム (SkeletalPlayer) [済]
- **ロジックの分離**: `SkeletalPlayer.gd` (物理・入力) と `CharacterDrawer.gd` (描画) の分離。
- **プロシージャル・アニメーション**: `_draw()` 関数と二分探索 IK による屈み動作の実装。
- **滑らかなアニメーション**: `visual_height_cm` による補間（lerp）の実装で、屈む動作を滑らかにした。
- **自動屈み (Auto-Crouch)**: RayCast2D センサー群による障害物検知と、Collider メタ情報からの正確な高さ取得。

### 3. ステージ構築 (StageBuilder) [済]
- `grep_simulator` のステージデータを Dictionary 形式で移植。
- `overhead` (ドア) / `ground` (足元) / `background` の CollisionLayer 分離。
- 描画の強化：ドア枠（柱）の追加、高さ(cm)ラベルの表示、基準線の可視化。

### 4. メインシーンとUI [済]
- **UI刷新**: 左サイドバー形式への統合。ゲーム画面を右側にオフセットして被らないように調整。
- **カメラ調整**: プレイヤーの腰〜胸付近を中心に映し、床下が映りすぎないようリミットを設定。
- **パラメータ設定**: 身長・頭身・股下比率をスライダーでリアルタイムに変更できる機能。

## 現在のタスク・次のステップ（Phase 2）

### 5. プロシージャル2Dキャラクターシステムの実装（優先：高）
- 現状の「線（棒人間）」による描画から、「ポリゴン等を使った体・服の描画」への移行。
- **体型計算の高度化**: `Global.gd` または描画クラスにて、頭身に応じた `body_params`（肩幅、胸・腰のY座標など）を算出する。
- **図形描画の導入**: `CharacterDrawer.gd` を改修し、`draw_polygon` 等を用いて上部・中部・下部に分割されたパーツや服を描画。画像は使わず完全にコードでデザインを表現する。
- **自動追従する服システム**: 伸縮可能な中部パーツと、固定比率の上部・下部パーツの概念を導入し、身長・頭身が変化しても服が追従する仕組みを構築。

### 6. ゲームフロー・シーン構成の構築（優先：中）
- 現在のテスト兼メイン画面（`Main.tscn`）から、正式なゲームフローへの分割。
  1. **TitleScene**: Start / Exit を持つタイトル画面
  2. **CharacterCreatorScene**: 身長、頭身、股下比率を設定できるキャラメイク画面
  3. **StageSelectScene**: ステージを選ぶ画面（初期は「家」のみ）
  4. **GameScene**: 実際のゲーム用メイン画面（既存の `Main.tscn` をベースにする）

### 7. アニメーションの拡張
- `AnimationPlayer` や `Skeleton2D` の導入可否を検討し、プロシージャルに描画されたパーツの自然な歩行・伸縮を表現する。
- 既存のIK（二分探索での屈み）を図形描画のスケールや回転にどう適用するかを実装。

## 開発メモ

### 身体パラメータの計算式
`Global.gd` で計算している各部位の比率：
- `head = height / ratio`
- `leg = height * legRatio / 100`
- `arm = height - leg - head - (neck * 2)`
- `armLength = head * 2.7`

### 屈みの二分探索
`CharacterDrawer.gd` 内で、目標の高さ（px）を満たす最小の `t` (ポーズパラメータ) を 15 回の反復で探索。
- `t` (0~1): 直立からかがみ（背中を丸める）
- `t` (1~2): 更に深く屈む（膝を曲げる）
