# 次アクション整理メモ

## 現状認識

今すでにある実装はかなり強い。

- バレー部ストーリーと分岐会話
- NPCの身長差リアクション
- 学期進行と身体測定UI
- 成長履歴とグラフ表示
- かがむ物理と頭上干渉
- 家、学校、駅などの比較しやすいステージ

不足しているのは要素数ではなく、これらを束ねるゲームループ。
現状は「歩いて探索して、反応やテキストを見る」体験はあるが、「今学期は何を優先するか」という判断がまだ弱い。


## いまの推奨方針

最初に強化すべき軸は、`パラメータ追加で判断を作る` 方向。

理由は以下。

- 既存の学期進行、測定、イベントキューをそのまま活かせる
- `self_confidence` / `self_complex` など、内面値の土台がすでにある
- 大きな新規マップや新アクションを作らなくても、ゲームらしさを増やせる
- 実装コストに対して体験の変化が大きい

つまり、次の一歩は「新しい面白さを大量に足す」よりも、「既存要素に意味のある選択を通す」こと。


## 推奨するコアループ案

時間粒度は、まず `1学期 = 1サイクル` で仮置きするのがよい。

流れのイメージ:

1. 学期のはじめに、今学期どこで過ごすかを選ぶ
2. 選んだ行き先に応じてイベントや比較体験が変わる
3. パラメータが変動する
4. 測定イベントで成長を確認する
5. 次の学期へ進む

候補エリア:

- 学校
- 家
- 繁華街
- 公園

この形なら、既存の「学期進行」と「身体測定結果UI」がそのままサイクルの締めになる。


## 優先順位

### 優先1: 判断を生む最小システムを作る

最初はパラメータを増やしすぎず、以下の2つに絞る。

- `目立ち度`
- `ストレス`

意図:

- 繁華街に行くと `目立ち度` が上がりやすいが `ストレス` も高い
- 家や公園では `ストレス` が下がりやすい
- 学校は中間で、既存ストーリーとつなぎやすい

これだけで、「今日は注目を取りに行くか、安全に過ごすか」という判断が生まれる。

### 優先2: 3エリアだけで縦切りを作る

まずは以下の3エリアだけで回る状態を目指す。

- 家
- 学校
- 繁華街

各エリアには最低限これだけ持たせる。

- 比較オブジェクト 1つ以上
- 固有イベント 1つ
- パラメータ変動ルール

公園は回復専用エリアとして後から足してもよい。

### 優先3: 初回体験コレクションを報酬にする

このゲームらしさを強く出せるので、早めに入れたい。

候補:

- 初めて頭をぶつけた
- 初めて制服が合わなくなった
- 初めて電車や改札で窮屈さを感じた
- 初めて誰かを大きく見下ろした

単なる数値増減だけだと味気ないので、「その成長で何が起きたか」を記録する。

### 優先4: 仮エンディングを先に作る

重いストーリーエンドではなく、まずは簡易リザルトでよい。

表示候補:

- 最終身長
- 成長グラフ
- 初回体験の取得数
- 行動傾向に応じた短い後日談

エンディングが先にあると、以後の実装が「何を増やせば最後が気持ちよくなるか」で判断しやすい。

### 優先5: セーブデータの保存項目を拡張する

新しいゲーム性を足す前に、保存対象を整理しておきたい。

追加候補:

- 目立ち度
- ストレス
- 初回体験コレクション
- 行動履歴
- エンディング分岐用の累積値


## 後から効きそうな案

以下は有望だが、最初の1本目としては少し後ろでよい。

### Y軸探索

身長帯によって見えるもの、触れるものが変わる案。
かなり相性は良いが、まずは判断ループを作ってから乗せた方が整理しやすい。

### リザルト強化と周回アンロック

成長タイプの違いを周回報酬として強める案。
すでに成長タイプ選択の土台があるので、エンディング実装後に広げやすい。

### 疲労システム

「かがむこと」にコストを与える方向。
魅力は強いが、最初から入れると説明量と調整量が増えるため、2段階目以降が無難。


## 今は後回しでよいもの

- 物理ベースの高度なスカート処理
- ミニゲーム
- SNS演出の作り込み
- 日単位の細かい時間管理
- 大規模な新ステージ追加

これらは面白さの核というより、核が固まったあとに効くポリッシュ寄り。


## まず着手するならこの組み合わせ

最初の実装テーマとしては、以下のセットが最もバランスがよい。

- `学期開始の行き先選択`
- `目立ち度 / ストレス`
- `家 / 学校 / 繁華街` の3エリア縦切り
- `簡易リザルト`

これができると、「成長を観察するだけ」から「どう成長を味わうかを選ぶゲーム」へ一段進める。


## レビュー時に確認したい点

- 1ターンの粒度は、本当に学期単位でよいか　OK
- 最初のパラメータは `目立ち度` と `ストレス` の2つで足りるか　そもそも目立ち度が上がるとどうなる想定だ？何がしたい？
- 最初の3エリアは `家 / 学校 / 繁華街` でよいか　家と学校はすでにある
- エンディングの区切りは卒業時点にするか、身長到達にするか　卒業で。一応学園ものだ
- バレー部ストーリーを「学校に行く意味」として主軸に残すか　主軸ではなくていい。オプションだ。ただ、代替案はあるのか？

追加でコメント
- ゲームの解像度が低く、細かい演出や描画が良くわからなくなっている。解決できるだろうか？　
- ストレスという感情項目がある。猫背にすることで、それを表現するのはどうだろう
- また現状のバグで、「歩幅と速度が合っていない」がある。大きくなっても、速度が上がらない。軽微ではあるが、見直してみてほしい
- 4. 優先4の「仮エンディング」は後でよい
現状のループが短くて周回できないため、エンディングより 「1学期の手触り」を先に整える方が実感しやすい。卒業まで遊んでもらう前に、1学期で「おっ」と思わせる体験が必要。
- ストーリーの外部ファイル化をしたい。今 MainScene.gd にダイアログがべた書きされている状態でエリアを3つに増やすと、管理不能になる。
