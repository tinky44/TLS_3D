## 開発メモ

### 身体パラメータの計算式

`Global.gd` で計算している各部位の比率：
- `head = height / ratio`
- `leg = height * legRatio / 100`
- `arm = height - leg - head - (neck * 2)`
- `armLength = head * 2.7`

### 屈みの二分探索

`CharacterPoseCalculator.gd` 内で、目標の高さ（px）を満たす最小の `t` (ポーズパラメータ) を 15 回の反復で探索。
- `t` (0~1): 直立からかがみ（背中を丸める）
- `t` (1~2): 更に深く屈む（膝を曲げる）
