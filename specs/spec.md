# プロジェクト仕様書 (spec.md)

本ドキュメントは、**Tall Life Simulator** の現在の実装状況および技術仕様を定義しますわ。

## 1. プロジェクト概要
高身長の主人公が、その体格ゆえに遭遇する日常の「摩擦」や「視線」、そして成長に伴う世界の小型化を体験する2D高身長シミュレーターですわ。

## 2. コアシステム仕様

### 2.1. 身体描画・ポーズシステム (`CharacterDrawer.gd`)
- **動的骨格生成**: `Global.gd` の身体パラメータ（身長、頭身、股下比率）に基づき、各パーツの座標をリアルタイム計算。
- **多角的描画**: 正面・背面・側面の3視点をサポート。
  - 髪型、服装（Tシャツ、セーター、ブラウス、パンツ、スカート等）、靴の描画をレイヤー管理。
- **ポーズ制御**: 立ち、歩き、座り（体育座り）の各状態をサポート。

### 2.2. 物理干渉・屈みシステム (`SkeletalPlayer.gd`)
- **自動屈み (Auto-Crouch)**:
  - 頭上のレイキャスト（センサー）により、鴨居やつり革などの障害物を検知。
  - 天井高に合わせて、`CharacterPoseCalculator.gd` による二段階の屈み（背を丸める ⇔ 膝を曲げる）を二分探索で最適化。
- **頭の衝突 (Head Bump)**:
  - 屈みが不十分な状態で低い障害物に進入した場合、衝突を検知。
  - **演出**: カメラシェイク、衝突警告（「ゴン！」等のSE的なテキスト表示）。

### 2.3. 多段階NPCリアクションシステム (`SkeletalNPC.gd`)
NPCはプレイヤーとの身長差をリアルタイムに判定し、以下の段階的な挙動を示しますわ。

| 身長差(Player - NPC) | 反応キー | セリフ例 | 特殊挙動 |
| :--- | :--- | :--- | :--- |
| **+60cm 以上** | `very_huge` | 「でかっ…！」 | **全力で後退/回避** |
| **+35cm 以上** | `huge` | 「見上げちゃう」 | **緩やかに後退/回避** |
| **+15cm 以上** | `tall` | 「背、高いな」 | 特になし |
| **-15cm 以下** | `shorter` | 「今日は私の方が高い」 | 特になし |
| **それ以外** | `same` | (無言) | 特になし |

- **視線同期**: プレイヤーの「目の高さ」を計算し、NPCが頭の角度（`look_head_angle`）を動的に変えて見上げる/見下ろす挙動を実行。

### 2.4. 成長・ライフサイクル (`Global.gd`)
- **身体測定**: 保健室の身長計で学期を進行。
- **成長ロジック**: 年齢・学期に応じた身長増加率を計算。過去の測定結果を履歴として保存。
- **平均比較**: 同年齢の平均身長と比較し、その乖離度を表示。

## 3. ステージ構成 (`StageBuilder.gd`)

現在実装されている主なステージと特徴的なオブジェクト：
- **家 (room / myroom)**: キッチン（低い洗面台・冷蔵庫）、玄関、自室。
- **駅・電車 (station / train)**: 自動改札、ベンチ、低いドア、吊り革（干渉物）、ロングシート。
- **屋外 (outdoor)**: 信号機、バス停、軽自動車（比較用）、郵便ポスト。
- **学校 (school / hallway / infirmary / schoolyard)**: 
  - 教室（低い机・椅子、黒板）、廊下、保健室（身長計・体重計・ベッド）、校庭（鉄棒、バスケゴール）。

## 4. 技術仕様
- **エンジン**: Godot Engine 4.x
- **座標系**: 1cm = 2.0px (`CM_TO_PX`)
- **描画方式**: `_draw()` 関数による動的ポリゴンおよび線画（スプライト未使用）。
- **データ保存**: JSON形式によるスロットセーブ (`user://save_slot_N.json`)。
