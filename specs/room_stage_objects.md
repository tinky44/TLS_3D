# 家ステージ (room) オブジェクト形状・配置まとめ

現在の `StageBuilder.gd` における家ステージのオブジェクトの描画形状と仕様のまとめです。今後の家具配置や背景拡充に向けた資料としてご活用ください。

## オブジェクトの基本構造と描画形状（アスキーアート）

### 1. ドア (`door_left`, `door_right`, `side_door`)
- **種類**: `overhead` (頭上障害物 / コリジョンあり)
- **特徴**: 左右の柱、上部の梁（厚さ20cm）、窓枠、ドアノブで構成。

```text
         [ 梁 ] (厚さ20cm)
+---------------------------+
|                           | <- y = -(height + 20)
+---------------------------+ <- y = -height (例: 200cm)
| 柱 |     +-------+     | 柱 |
|    |     |   窓  |     |    |
|    |     |       |     |    |
|    |     +-------+     |    |
|    |                   |    |
|    |         [ ]<--ノブ|    |
|    |                   |    |
:    :                   :    :
|    |                   |    |
+----+-------------------+----+ <- y = 0 (床)
```

### 2. シーリングライト (`ceiling_light`)
- **種類**: `overhead` (頭上障害物 / コリジョンあり)
- **特徴**: 天井付近からぶら下がる照明。

```text
+---------------------------+ <- y = -height (215cm)
|        [ ライト ]         |
+---------------------------+
|                           |
:                           :
+----+-------------------+----+ <- y = 0 (床)
```

### 3. レンジフードとキッチン台 (`range_hood`, `kitchen_counter`)
- **種類**: `overhead`, `ground`
- **特徴**: 上部に吸い込み口を持つレンジフード、下部に扉の線をあしらったキッチン台。

```text
         [ 本体 ] (厚さ20cm)
+---------------------------+
|                           | <- y = -(180 + 20)
+---------------------------+ <- y = -180cm (range_hood)
| 柱 | +---------------+ | 柱 |
|    | | [ 吸い込み口 ]| |    |
|    | +---------------+ |    |
|    |                   |    |
:    :                   :    :
|    |                   |    |
|    +-------------------+    |
|    |   |           |   |    | <- y = -80cm (kitchen_counter)
|    | 扉|     扉    | 扉|    |
|    |   |           |   |    |
+----+---+-----------+---+----+ <- y = 0 (床)
```

### 4. テーブルと椅子 (`table`, `chair`)
- **種類**: `ground` (足元障害物 / コリジョンあり)
- **特徴**: 天板と脚が色分けされたテーブルと、背もたれ付きの椅子。

```text
       [天板]                [座面]
+-------------------+   +-------------+  <- y = -70cm (table), y = -45cm (chair)
|                   |   |         |背 |
+-------------------+   +---------|も |
| 脚 |         | 脚 |   |脚 |     |た |
|    |         |    |   |   |     |れ |
|    |         |    |   |   |     |   |
+----+---------+----+   +---+-----+---+  <- y = 0 (床)
```

### 5. 洗面台 / 鏡 (`washstand`)
- **種類**: `background` (背景オブジェクト / すり抜け可能)
- **特徴**: 背景の枠の内側に、鏡部分（明るい水色の四角）が描画される。現状は180cmの高さ。

```text
+---------------------------+ <- y = -height (180cm)
|            [枠]           |
|   +-------------------+   |
|   |                   |   |
|   |                   |   |
|   |        [鏡]       |   |
|   |                   |   |
|   |                   |   |
|   |                   |   |
|   +-------------------+   |
|                           |
:                           :
+---------------------------+ <- y = 0 (床)
```

### 6. シャワー (`shower`)
- **種類**: `background` (背景オブジェクト / すり抜け可能)
- **特徴**: 現状は単なる青みがかった半透明の矩形。装飾は特に描かれていない。
