# 家ステージ (room) オブジェクト形状・配置まとめ

現在の `StageBuilder.gd` における家ステージのオブジェクトの描画形状と仕様のまとめです。今後の家具配置や背景拡充に向けた資料としてご活用ください。

## オブジェクトの基本構造と描画形状（アスキーアート）

### 1. ドア (`door_left`, `door_right`, `side_door`)
- **種類**: `overhead` (頭上障害物 / コリジョンあり)
- **特徴**: 左右の柱、上部の梁（厚さ20cm）、窓枠、ドアノブで構成。

```text
         [ 梁 ] (厚さ20cm)
+---------------------------+
|                           | <- y = -(height + 20)
+---------------------------+ <- y = -height (例: 200cm)
| 柱 |     +-------+     | 柱 |
|    |     |   窓  |     |    |
|    |     |       |     |    |
|    |     +-------+     |    |
|    |                   |    |
|    |         [ ]<--ノブ|    |
|    |                   |    |
:    :                   :    :
|    |                   |    |
+----+-------------------+----+ <- y = 0 (床)
```

### 2. レンジフード (`range_hood`)
- **種類**: `overhead` (頭上障害物 / コリジョンあり)
- **特徴**: ドアと同様のオーバーヘッド構造（左右の柱、上部の梁）を持ち、底辺付近に換気扇の吸い込み口（黒い四角）が描画される。

```text
         [ 本体 ] (厚さ20cm)
+---------------------------+
|                           | <- y = -(height + 20)
+---------------------------+ <- y = -height (180cm)
| 柱 | +---------------+ | 柱 |
|    | | [ 吸い込み口 ]| |    |
|    | +---------------+ |    |
|    |                   |    |
|    |                   |    |
:    :                   :    :
+----+-------------------+----+ <- y = 0 (床)
```

### 3. 洗面台 / 鏡 (`washstand`)
- **種類**: `background` (背景オブジェクト / すり抜け可能)
- **特徴**: 背景の枠の内側に、鏡部分（明るい水色の四角）が描画される。現状は180cmの高さ。

```text
+---------------------------+ <- y = -height (180cm)
|            [枠]           |
|   +-------------------+   |
|   |                   |   |
|   |                   |   |
|   |        [鏡]       |   |
|   |                   |   |
|   |                   |   |
|   |                   |   |
|   +-------------------+   |
|                           |
:                           :
+---------------------------+ <- y = 0 (床)
```

### 4. シャワー (`shower`)
- **種類**: `background` (背景オブジェクト / すり抜け可能)
- **特徴**: 現状は単なる青みがかった半透明の矩形。装飾は特に描かれていない。

```text
+---------------------------+ <- y = -height (190cm)
|                           |
|                           |
|      [ シャワールーム ]   |
|         (単なる矩形)      |
|                           |
|                           |
|                           |
:                           :
+---------------------------+ <- y = 0 (床)
```

## 今後の拡充に向けた見直しポイント（案）
1. **レンジフード周辺の拡充**：現状、キッチンのコンロや調理台がなく、宙に浮いた換気扇だけが存在するため、下部に `ground` オブジェクトとしてキッチン台（高さ85cm程度）などを追加すると良さそうです。
2. **`side_door` の幅**：30cm幅のドアとなっているため、横向きのドアのつもりであれば、パースや描画方法を調整するか、別の家具にするか検討の余地があります。
3. **洗面台の形状**：現状は「大きな鏡」のような描画であるため、下部に洗面ボウル（高さ80cm付近）などを書き足すとそれらしくなります。
4. **家具の追加**：机やベッド、窓など、家らしさを演出する背景オブジェクトの追加が必要ですわね。
