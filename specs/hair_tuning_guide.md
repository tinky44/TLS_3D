# 髪型のチューニング・微調整ガイド

「髪のシルエットはいい感じだけれど、目が隠れてしまっている」などの際に、ご自身でスクリプトの数値を調整できるようにするためのマニュアルです。変更するファイルは `godot-project/scripts/CharacterDrawer.gd` の `_draw_side` (横向き描画関数) の中となります。

## 1. 横顔の露出面積（縦のライン）を調整する

横髪が顔を隠す「スパッと落ちる縦の境界線」の位置を前後にズラします。
目が横髪で隠れてしまっている場合は、ここを下げる（プラスにする）ことで解決します。

```gdscript
# CharacterDrawer.gd 内、横髪の計算部分
var cut_dist = -hr * 0.1 # マイナス＝中心より前
```

- **顔の露出を増やしたい（目を見せたい）場合**: 
  `-hr * 0.1` という数値を `0.0` または `+hr * 0.1` など、プラス側に変更してください。ラインが後退し、表情がよく見えるようになります。
- **もっと顔を隠したい場合**: 
  `-hr * 0.2` や `-hr * 0.3` など、マイナスの値を大きくすると、髪が顔の前面へ迫り出します。

## 2. 前髪の形や目へのかかり方を調整する

前髪は4つの頂点を持つポリゴンで表現されており、これらの頂点を動かすことで形を自由にチューニングできます。

```gdscript
# CharacterDrawer.gd 内、前髪のポリゴン点群
var bangs_pts = PackedVector2Array([
    # ① 横髪のラインの一番上のあたり（頭上の起点）
    head_center + back_dir * cut_dist + up_dir * (R * cos(min_ang)),
			
    # ② 前方に突き出す先端 (ここをいじって長さを調整)
    head_center + fwd_dir * hr * 1.0 + up_dir * hr * 0.6,
			
    # ③ 前髪の毛先 / 額・目の上のライン 
    head_center + fwd_dir * hr * 0.7 + down_dir * hr * 0.1,
			
    # ④ 横髪の顔側ラインと接触する点
    head_center + back_dir * cut_dist + down_dir * hr * 0.1
])
```

- **目が前髪で隠れてしまっている場合 (③の調整)**:
  一番のポイントは ③ の点です。現在 `down_dir * hr * 0.1` (つまり下方向へ0.1進む) となっていますが、これを **`up_dir * hr * 0.1`** に変更するか、あるいは `0.0` にすることで、毛先が上昇し、目がはっきりと見えるようになります。
- **前髪の膨らみ/突き出しを調整したい場合 (②の調整)**:
  `fwd_dir * hr * 1.0` の `1.0` を `0.8` などに減らすと前髪が短くなります。
  `up_dir * hr * 0.6` を `0.8` にすると、前髪がより上向きにピッと跳ねるようになります。

## 3. 後頭部のボリュームの調整

頭の丸みを担っている円弧の半径をいじることで、後頭部のボリュームが調整可能です。

```gdscript
var R = hr * 1.05 # 髪の丸みの半径
```
- 後頭部をより丸く膨らませたい場合は `1.1` や `1.2` にしてください。
- ピタッとしたストレートにしたい、頭部の小ささを強調したい場合は `1.0` や `0.9` などに小さくしてください。


これらを保存した上でGodotエディタを見ていただくと、リアルタイムに近い形でシルエットが変化しますので、自分好みのベストなポイントを探してみてください！
